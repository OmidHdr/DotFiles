# Neovim Backend IDE Cheatsheet

Leader is `Space`.

| Keys | Action |
|---|---|
| `<leader>ff` / `fg` / `fb` | Files / text / buffers |
| `<leader>e` | Explorer |
| `<leader>la` / `lr` / `lf` | Code action / rename / format |
| `gd` / `gr` / `K` / `<C-k>` | Definition / references / hover / signature |
| `[d` / `]d` / `<leader>xx` | Diagnostics |
| `<leader>jo` / `ju` / `jC` | Imports / update project / compile |
| `<leader>jv` / `jc` / `jm` | Extract variable / constant / method |
| `<leader>jn` / `jt` | Run nearest JUnit test / class |
| `<leader>jd` / `jD` | Debug nearest JUnit test / class |
| `<leader>jr` / `jb` | Select run / debug Java main |
| `<leader>db` / `dB` | Breakpoint / conditional breakpoint |
| `<leader>dc` / `dl` / `dr` / `dp` | Continue / last / restart / pause |
| `<leader>dn` / `di` / `do` | Step over / into / out |
| `<leader>dt` / `du` / `dR` / `de` | Terminate / UI / REPL / inspect |
| `<leader>mr` / `md` | Spring Boot run / debug |
| `<leader>mt` / `mc` / `mp` / `mv` | Test / clean test / package / verify |
| `<leader>ms` / `mf` | Spotless / Flyway |
| `<leader>tt` or `Ctrl-\` | Toggle terminal |
| `<leader>gg` | LazyGit |
| `<leader>sr` / `ss` / `sd` | Restore / select / skip session |
| `<S-h>` / `<S-l>` | Previous / next buffer |

In a process terminal, `Ctrl-C` stops Spring Boot or Maven.
